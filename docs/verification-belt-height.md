# 传送带高度与分拣器连接验证

2026-09-25，在 `AutomaticDSP-redblue-opening-20260925` 实机验证。

## 修复原因

旧蓝糖桥带包含架高约 1.33 米的带段，却通过分拣器连接地面研究站。接口原先直接调用 `BuildTool_Inserter.CheckBuildConditions`，遗漏了原生 `DeterminePreviews` 中的端点姿态配对条件。

接口现在保留原生角度容差：涉及传送带时小于 11 度，建筑之间小于 14 度；检查两个端点朝向及其与连接方向的偏差。高度按球面径向理解，不能比较世界坐标的 y。传送带端点从四个原生水平朝向选择匹配方向，最终仍执行原生碰撞和距离校验。

## 实测结果

- 穿过研究站的地面带线被 `Collide` 拒绝，没有生成预建。
- 同一平面位置的地面带线、架高带线分别建成，说明架高本身合法，与建筑堆叠无关。
- 地面研究站 107 的槽位 11 连接架高带段：`invalid_connection` / `NeedConn`，高度差 1.3376 米，姿态偏差 26.8233 度，没有创建分拣器。
- 同一槽位连接地面带段：分拣器 277 成功建成。
- 外侧直线路径擦到炼油厂边缘时被原生碰撞拒绝；读取碰撞盒后改为转弯绕行，路线成功建成。
- 拆除了旧桥带及跨层分拣器，保留原有缓冲箱与研究输入。新路线从研究站外侧绕行接入缓冲箱，研究站 107 的积压产物清空，箱内已有 102 个蓝糖。

新进程任务 1–10 的结果保存在本地 `.tools/opening-validation/belt-height-verification.json`，包括失败负例与成功建造结果。临时架高测试带已拆除。

构建通过（0 警告、0 错误），skill 格式检查通过。接口没有增加自动选路或自动避障策略。
