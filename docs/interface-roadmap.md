# 接口能力与 TODO

开发规划，依据 2026-09-24 项目状态整理。

已实现接口见 [API 文档](api.md)。以下为后续待支持或待验证项目：

| TODO | 当前可推进 | 待补能力 |
| --- | --- | --- |
| 跨行星与星际航行 | 当前行星准备工作，查询可达的星系和资源信息 | 原生航行控制及到达确认 |
| 物流站供需、槽位与航线设置 | 观察组件、建设允许的建筑、准备物品 | 原生设置及运输效果验证 |
| 戴森球层、节点、框架、壳面编辑 | 探索 `data.dysonSpheres` 可读状态 | 原生编辑、约束校验和施工验证 |
| 工厂及戴森球蓝图导入、应用 | 准备文件，核对目标与解锁条件 | 各类蓝图的原生应用及完成验证 |
| 射线接收、发射目标与增产模式设置 | 观察可达组件，准备配套产线 | 各专用模式的设置接口 |
| 战斗、地形改造 | 查询警告，评估对计划的影响 | 相应原生操作与约束 |
| 连续产速、功率及跨行星统计验收 | 产出等待、运行状态检查与字段发现 | 实测累计量、单位、时间基准和汇总方法 |
| 完整物品、配方和建筑信息查询 | 使用现有原型摘要及可读组件 | 热值、配方时长、设备速度与适配信息，以及属性筛选接口 |

物品信息接口计划支持按燃烧热值等属性发现候选。上线后在查询文档维护实际入口、字段单位、筛选、分页和原型／实例值的区别；候选比较由 Agent 完成。
