# 产线建设与运行

## 场地和布局

行星表面的球面几何、建筑朝向、端口、地形和周边实体共同决定位置与连接。方案经原生建造校验后，核对实际落点。

靠近海岸时，先查询原生地形高度和建筑 `landPoints`，采样每个落地点及吸附余量，再决定整排布局。中心在陆地上不代表整个占地可建；`NeedGround` 优先排查落地点跨水面或低地，不要归因于植被，也不要自动铺地基绕过规则。查询契约见 [提示与地形查询](../interface/game-state.md#提示与地形查询)。

矿机选址综合覆盖点、剩余矿量、场地、电力、输出通路和带长。供电规划结合已有电网。重复设备可沿易扩展方向排列，为进出料和后续建设留空间；试建或批量建设取决于现场信息的充分程度。

抽水机采集星球海洋，不使用矿脉。先查 `localPlanet.waterItemId` 确定海洋物品（如水或硫酸；0 表示无海洋物品），并与建筑 `prefabDesc.waterTypes` 核对；不要按星球名称假定产物。结合原生 `landPoints`、`waterPoints` 和 `waterHeight` 检查岸边落点与取液点，最终保留原生 `NeedWater` 等校验。建成后核对采集组件实际产物及持续输送，不能在普通水海洋上指定生产硫酸。

先规划整条产线的建筑排列、朝向、端口、进出料带、缓冲和供电，再施工；不要逐个放置建筑后才寻找连接路线。布局按以下优先级取舍：

1. 保证原料持续送达、主副产物都有出口；建筑贴近对应带线，分拣器尽量一格。
2. 同工序建筑紧凑成排，共用直线进出料带；同品产出汇入公共缓冲，避免每台机器独立囤料。
3. 在原生地形、碰撞和吞吐允许的范围内缩小整条产线占地，保留必要的输送、供电与扩建空间。比较平面与立体方案，不能为了少一座电塔而明显拉长输送距离。
4. 拐弯用于避让矿区、地形或必要交叉；消除空地上的折返、反复偏移和可避免的绕路。减少拐弯是为了保持连续可建空间、缩短分拣距离和提高密度，不把拐弯数量本身当成吞吐指标。

选址同时检查矿簇及未来采矿机、出矿带的作业空间，抽水机、电塔和过路带也应避让。原生允许建筑或传送带覆盖矿点，不代表该布局适合后续开采。

## 连接与吞吐

明确物品来源、去向和建筑端口。分拣器从来源取物、向目标放物；连接传送带时确认对应带段及流向。按建筑机制选择传送带直连或分拣器连接。

施工前可读 `items.prefabDesc.portPoses/slotPoses` 规划朝向；落成后通过 `factory.objectConnections(entityId: ...)` 重读实际模型端口、姿态和连接。传送带使用 `beltPorts.index`，分拣器使用 `sorterSlots.index`，保持原生编号；带段端点按原生特殊规则处理。AI 计算坐标及路径，任务完成后复查连接对象、槽位与方向，再观察物流。查询为空或实体已回收时重新观察，不能复用旧端口；详细契约见 [原型与连接](../interface/prototypes-and-connections.md)。

放置前先区分原生传送带直连端口与分拣器取放插槽，不把两者当作同一种入口。先确定原料来向和产物流向，再根据端口位置、朝向选择建筑 `rotation`，给直连带留出出口直线段和转弯空间，也让分拣器插槽尽量靠近对应带线。抽水站、油井、物流站等仅作为直连示例，实际能力以查询到的端口为准；不要先固定建筑朝向再绕长带补接。

采矿机等设施可通过端口直接接出传送带；普通加工设施通常由分拣器送入原料、取出产物。交叉输送可使用不同高度的传送带，同时核对坡度、端点和碰撞条件。

传送带架高是路径高度与坡道问题，与建筑 `multiLevel` 垂直堆叠不同。交叉、避让和多路输送时，比较局部抬升跨越与平面绕行，合理使用不同高度减少地面占用；计入坡道长度、转弯空间和可用净空，避免把长绕路简单搬到空中。通过路径点的球面径向高度表达架高，遵守原生高度、坡度和空间碰撞限制；不能用全局 `y` 判断同一水平面。分拣器取放段应与所接建筑层的实际插槽同高，并留出平直段；连接底层时下降到其插槽高度，连接上层时按上层实际姿态计算，不能用斜跨高度的分拣器补救架高带。接口还会校验原生端点朝向容差，少量球面／模型偏差不等于允许跨架高层。

不要把研究站等建筑之间的视觉空隙直接当作可穿越通道。查询实际碰撞体及完整路径，避免传送带穿过建筑体积；必要时移到建筑外侧，或在确有净空的高度跨越。建成后复核实际带段高度及连接。

规划前查询目标物品 `prefabDesc.multiLevel` 判断是否支持垂直堆叠，不根据建筑名称或固定白名单推断。字段为 `null` 或缺失时先做字段发现，不能当作支持。支持堆叠时优先比较垂直扩建与平铺，再按[堆叠属性与实例检查](../interface/prototypes-and-connections.md#垂直堆叠)核对搭接点、类型兼容、旋转和当前顶层。堆叠可节省占地和底层供料线，但仍需核对科技层数上限、整叠吞吐与供电。使用 `placeBuilding.stackOnEntityId` 指定上方槽位空闲的实体，最终以原生建造校验为准，建成后检查上下层连接及实际工作模式。

相邻同配方建筑可比较分拣器直接转送原料与共用传送带，研究站、发电厂等应先确认原生可取出的物品及实际转送效果。直连可省带，但分拣器耗电，串联吞吐受距离和上游取料影响；核对后排持续供料，避免只凭相同配方推定能够转送。垂直研究站优先利用原生层间供料。

堆叠增加生产能力或储量，不会自动增加底层入口的带宽。多层储物仓、研究站扩高后，按整叠各物料的需求检查进出料带、分拣器与层间传递能力。若瓶颈在底层入口，比较升级带线与分拣器、增加并行带、通过架高带向上层分段供料或从上层取货；先查询目标层实际端口并确认原生允许连接，不能仅凭支持堆叠就假定任意层都可取放。

分层供料应明确每条带负责的物料、层组和流量，配套足够的上游产量及独立输送能力。例如整叠研究站需求超过一条带的容量时，可在原生允许连接的上层增加独立供料带，分担底层入口负载；从同一条已饱和的带分出多个高度并不会提高总带宽。建成后核对各层实际收料、生产或研究速率及输出通畅情况，确认吞吐提升，而不是只确认架高带建成。

传送带可布置在水面，跨水路线可用于缩短带长；不要把普通建筑的陆地占地要求套到传送带上。路线仍以原生高度、坡度和碰撞校验为准。

四向分流器可用于分配物料、设置输出优先级及筛选输出。共用原料同时供给多条产线时，结合科研、燃料和其他需求安排分配，并检查各出口的实际供料。

共享供给线按同一种物料组织。不同产物分别使用专用出口、过滤分拣器、传送带和缓冲；红蓝矩阵等消耗比例随科技变化的物品不混放在同一箱子后共用出箱分拣器。缓冲仓靠近消费端，在原生碰撞和连接距离允许的范围内缩短出箱钩爪，按各物料需求分别限制容量。

按整条产线的总需求、配方速率、设备速度与增产效果计算设备数量，再分配共享供料；不要固定复制“一炉一机”或“一炉一电站”。通过实际吞吐和缓冲变化验证配比，避免大量独立设备各自囤料而下游仍缺料。

汇流线路按总需求计算吞吐，分拣器能力结合等级、搬运距离和堆叠状态核实。扩产时同时检查运输容量。

已有线路发生运输瓶颈时，优先比较升级传送带或分拣器与增加并行带线、重排布局的成本。区分上游产量、带宽和分拣器搬运能力，升级真实瓶颈；结合科技、材料和耗电决定，避免用升级掩盖缺料或断电。

分拣器（钩爪）优先采用最短可行连接，尽量让传送带贴近对应建筑端口，减少伸缩和往返距离。规划时先调整建筑朝向、相邻位置或带线位置，再考虑跨越多格；确需长距离时，按实际距离核对搬运能力，避免只按分拣器等级估算吞吐。缩短连接仍需保留合法端口和必要的进出料通路。

跨行星和星际供应还需考虑供需配置、运输工具、能源、距离及往返延迟，并用缓冲吸收运输波动。评估远端方案时计入前哨准备和持续补给成本。

## 建造与拆改

长带或成排建筑施工时，让机甲沿施工区分段前移，缩短无人机往返距离；站位兼顾待建对象、通行空间和后续施工方向。建造创建预建后释放机甲通道，后续 `moveTo` 可在 `waitingBuilt` 期间跟进。合理分段并选择靠近待建点的停留位置，避免过早远离导致无人机往返增加或停止施工；连接等实体依赖仍等实际落成。站位和分段由 Agent 规划，仍遵守原生下发范围与建造规则。

区分设计、等待建造和实际落成，随后验证配方、连接、供电与产出。布局验收同时检查整条产线占地、分拣距离、带线是否无故绕行，以及矿区和扩建空间；不能只以逐条连接成功作为完成依据。拆改时考虑相邻电网、输送与下游供应的影响，完成后复查连接和回收物品。

修复断链后，沿物料来源检查到上游设备和缓冲仓，恢复拆改影响的供料。验收自动生产时停止手动补料，按游戏 tick 观察多个连续窗口的产出变化；分别报告连接修复、自动供料及库存续航，不能用一次手持投料的成功代替自动产线验收。

## 物料供应与仓储

物流配送器放在储物仓最上层，以 `stackOnEntityId` 指定；继续叠箱会抬升配送器并更新连接。配置物品、机甲配送模式、箱间 Supply/Demand 和机器人后，供货箱选择、配对与发货由游戏完成。按当前 `history` 范围、电力、`pairCount` 和实际收货判断是否运行，接口见 [游戏控制](../interface/game-control.md#配送器物流背包与指定转移)。

补料时综合可用库存和现有生产。取料前考虑库存对关键产线的保障作用，为研究、建造和机甲取料保留明确的材料预算。仓储按材料用途组织，作为供应和运输波动的缓冲。

持续供应由生产或运输补充，库存可维持时间按可用数量与净消耗速率估算。扩产时检查共用库存被哪些产线消耗，以及补给速度能否覆盖总需求。

## 工厂供电

### 能源选择

新增或扩充供电前，比较当前已解锁且能落实供给的电源，优先选择当前条件下效率最高的方案；不能因为风机易造、无需燃料就持续复制风电。效率按目标所需的持续净供电、单位占地、建设及运行资源成本评估，计入加工、运输耗电和日照等波动；单台额定功率或单件燃料热值不能独自证明最优。风电适合其条件确有优势或短期启动的场景，新能源解锁、燃料链建立或供电瓶颈出现时重新比较，并在更优供给稳定后替换旧方案。

火电燃料优先评估已解锁且能持续供应的更高级燃料。煤直接燃烧只作为开局或断供时的临时方案；具备加工能力后优先升级为石墨，并继续评估后续燃料。比较时计入加工耗电、原料成本及持续产量，不能只看单件热值。切换前接通新燃料并验证供电，再停掉旧燃料输入，让机组消耗已有缓冲；科研原料与燃料分别核对供需，避免互相抢料。

由当前游戏物品和发电建筑数据取得候选，结合以下因素选择工厂能源：

- 目标设备允许的燃料类别与使用条件；
- 热值、发电效率、持续功率和发电条件；
- 解锁状态、现有库存、加工成本和其他生产用途；
- 获取距离、运输容量和持续补给速度。

比较收益时计入发电设施及燃料产线的建设和准备时间。

### 火电接力供料与燃料升级

成组火电站优先比较接力供料布局：建筑紧凑成排，用分拣器从前一台的燃料槽向后一台传递燃料，一条进料带可供应多台电站，减少为每台单独铺带的占地和改造工作。接力通过实际建筑插槽和分拣器完成，不是假定相邻电站会自动传料；先查询可用端口，并以原生连接校验和实际传料为准。

按整组满载燃料需求核算入口带宽，链上每段分拣器要承担其下游全部电站的消耗，并留出启动填充和恢复供料的余量。新建或扩长后观察首端、中段和末端燃料库存及实际出力；前端有料不代表末端供料充足。接力过长或搬运能力不足时，比较升级分拣器、分段补料和并行分组，不把单条接力链无限延长。

优先从共用燃料入口切换更高级且兼容的燃料，复用原有接力连接；核对所有相关分拣器的物品过滤，避免仍只允许旧燃料。先确认新燃料能持续供给，再停止旧燃料输入，观察旧缓存消耗和新燃料逐段进入。单位有效热值更高的燃料，在相同供电负荷下通常能维持更久、降低每秒物品流量和传送带／分拣器压力；这不等于单台电站额定功率同步提高，仍要计入燃料制造、运输及原料成本。

燃料方案同时评估增产剂喷涂。可在共用进料段集中喷涂，利用燃料增产效果减少达到同等供电所需的燃料数量；按当前游戏的燃料适用性和增产等级计算有效热值，不套用制造配方的产量或耗电倍率。计入增产剂生产与运输、喷涂设施耗电，并核对增产点在接力过程中保留、末端收到已喷涂燃料；最终按相同负荷下的实际燃料消耗和净供电确认收益。

### 电网运行

分别观察理论能力、实际出力、电网需求、覆盖与储能。局部电网连接、燃料供应和发电条件共同影响持续供电。

把发电容量与供电覆盖分别规划：按整组设备的负载和现有余量配置发电设施，用输电塔把电力传到生产区并覆盖多台建筑，不按每台生产建筑配一台风力发电机。读取实际连接距离、供电范围和现有电网，优先复用覆盖，在保持连通和设备供电的前提下减少电塔数量；电塔只扩展输电与覆盖，不能补足发电功率。

相邻且供电需求一致的生产区优先合并电网，共享发电余量、减少重复设施，便于统一检查。燃料生产、启动保障或确有独立供电需求的区域可分网，明确每个电网的电源、负载与边界，避免无目的地拆成多个小网。合并前核对合计供需及短缺影响范围，分割前确认各网有足够的独立电源；建造或拆改电塔后复查实际电网归属、连通与覆盖，避免意外合网或断电。

燃料生产若依赖短缺的主电网，可能进一步降低发电供给。可按现场需要配置燃料缓冲或独立供电。发生这种连锁短缺时，先利用库存燃料或独立电源恢复燃料生产与输送，再逐步恢复其他负载；扩产前比较新增耗电和燃料链的持续供给能力。

## 配方与增产

用配方及设备能力估算产能，以运行状态和实际产出验证。核对设备兼容、解锁、原料、输送和供电。替代配方的收益包括上游链缩短，也要计入特殊资源获取和副产物处理成本。

机器取整、原料与增产剂消耗、增产/加速比较及计算脚本见 [产线需求计算](production-calculation.md)。

## 定位瓶颈

出现瓶颈或到达定期检查窗口时，执行[效率复核](goal-planning.md#定期效率复核)，将升级科技、换配方、升级现有设备与新增高级产线一并比较。以下现象用于定位原因，不直接等同于需要加机器或加电站。

| 现场现象 | 优先检查 |
| --- | --- |
| 配方为空或没有工作目标 | 配方、设备兼容性及解锁 |
| 缺料 | 短缺原料的上游产出、库存、输送方向和容量 |
| 输出堵塞 | 主产物与副产物出口、仓储容量、下游需求 |
| 工作进度普遍变慢 | 电网供给、燃料链和供电覆盖 |
| 部分设备缺料 | 分配方式、汇流竞争与连接 |
| 库存持续下降 | 上游持续供给与实际消耗的差额 |
| 矩阵充足但研究慢 | 送达情况、研究模式、材料组合和研究能力 |

多产物配方需同时安排各输出去向；任一出口积压都可能阻塞整条线。仓储可暂时缓解波动，长期方案取决于净供需。副产物用于发电时，计入实际电力负载对燃料消耗的影响。

## 验证产出

区分理论产能、实际生产、实际消耗和库存净变化。根据目标选择范围与游戏时间窗口，同时观察库存趋势、周期性供电及运输波动。科研目标观察研究端，新建产线目标需能归因到相应设施。
