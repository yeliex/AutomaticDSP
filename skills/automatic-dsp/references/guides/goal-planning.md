# 科技推进与产线规划

## 选择当前值得投入的工作

围绕目标所需科技，判断当前限制在前置解锁、材料供应、电力、运输还是研究能力。建设和扩产的近期收益，是让相关科技更快完成，并为后续目标提供能力。

例如白糖目标尚缺前置科技时，先补齐对应矩阵供应；若研究材料生产受缺电影响，先改善供电。已有白糖时，再根据实际瓶颈决定扩充哪一环节。生产、电力、物流和机甲升级的投入都可按准备成本与节省时间比较。

由当前物品、配方和建筑数据获取候选，结合解锁、可获得性、设备适配及成本选择。手搓与自动化的取舍见 [机甲操作](mecha.md)，工厂能源选择见 [产线供电](production.md#工厂供电)。

提前规划后续科研及其材料供应，尽量始终保持有正在推进的研究。当前项目完成前，核对下一批目标科技的显式、隐含前置和原生可入队状态，提前加入可研究且符合目标优先级的项目；前置未完成的项目在解锁后及时补入。不要只确认队列非空，还要检查实际研究进度和缺料停滞；必要目标暂时缺料时，可结合材料预算安排有收益的可推进研究，同时补齐目标所需供应。

## 升级落地

无论最终目标是科技、产速还是建设，都把物流与提升生产、供电、施工和科研效率的科技作为优先候选。按剩余任务中的累计收益比较研究、材料、施工和切换成本；能够减少反复手动运输、缩短建设周期或解除持续瓶颈的升级，提前准备并优先落实，不等到主目标前置全部解锁才建设配套。

科技完成后立即复核受影响的配方、设备、运输能力和属性，为有收益的应用安排材料与施工任务，尽快投入实际产线。记录实际运输或产出变化及替代的旧流程；若暂缓，明确当前缺少的条件与再次检查的触发点，不能只记录解锁而长期不使用。首批钛硅人工运输只用于启动预算，具备星际物流能力后优先建成持续运输，避免继续靠往返背料支撑科研。

优先不等于无条件研究全部升级。计入矩阵消耗和对关键解锁的延后；收益无法在剩余目标中回收、当前没有适用场景的升级可暂缓。

## 定期效率复核

长任务在每轮阶段规划时复核效率；持续建设或等待科研期间，默认每经过约 5–10 分钟游戏时间做一次轻量检查，按生产周期与风险调整间隔。科技解锁、原料来源变化、产线投产或明显的缺料、堵料、缺电出现时提前检查，不必等到定期窗口。记录上次检查的游戏 tick、结论和下次触发条件；没有相关变化时复用已有候选，不反复扫描整个目录或打断正在运行的任务。

按 [统计诊断流程](production.md#基于统计优化产线)定位目标链的限制，再比较以下途径。

| 途径 | 复核重点 |
| --- | --- |
| 升级科技 | 当前可研究的等级及实际效果，能否改善建设、采集、输送、运力、供能或科研瓶颈；计入前置科技、矩阵消耗、研究时间和对关键解锁的延后 |
| 优化配方 | 按下节查全替代与组合配方，比较净交付、共同原料、副产物出口及资源获取成本，不只比较单机产速 |
| 升级现有产线 | 更高等级设备、传送带、分拣器、增产／加速和布局调整；核对兼容性、整条链的供料、出口与新增耗电，避免只把瓶颈推到下一段 |
| 增加或替换产线 | 比较扩建现有方案与建设采用更高级设备、配方或资源路线的新产线；计入解锁、设备材料、供电、运输、施工时间及切换期间的供应 |

用同一目标产量或科研进度比较候选的材料、能源、准备与切换时间，优先选择能在剩余目标中收回投入的方案。升级研究也占用矩阵和研究时间；缺料时先补供应，不能以研究速度升级代替。调整科研队列前重读队列，调整后确认顺序及已投入进度。

简记瓶颈、采用或暂缓的方案、预期收益及复核条件。能源取舍见 [工厂供电](production.md#工厂供电)，改造基线与复测统一按统计诊断流程执行；目标已满足且没有可回收收益时继续主目标。

## 配方候选复核

出现新建或扩产、持续缺料、副产物积压，或相关科技解锁、资源来源变化时，复核受影响的物料链。先区分供电、运输和出口故障与真实产能不足，再选择扩产或换配方；不要在未比较候选前默认复制原设备、开更多矿或叠储罐。

1. **列出缺口与积压。** 记录目标物料的需求、现有稳定供给，以及共用原料和副产物的库存趋势。库存能撑多久与持续产能分开计算。
2. **从数据查全候选。** 使用[完整配方目录](../interface/prototypes-and-connections.md#完整目录和字段发现)，按每个 `results.itemId` 建立“物品 → 所有产出配方”，按每个 `items.itemId` 建立“物品 → 所有消耗配方”。多产物配方的每种产物都进入索引，同物品的多个配方保留为列表，不能被覆盖或只取第一项。缺料时查产出候选，积压时查消耗候选，并检查两者是否能由同一配方或配方组合解决。
3. **筛选可落实的路线。** 核对当前解锁、设备适配、原料来源及运输、电力、全部产物出口。采矿、海洋采集、轨道采集和进口等非普通配方来源也纳入相关比较；未解锁路线只作为带明确前置成本的候选，不能当作现有能力。新解锁后刷新可用状态，无需每次重新扫描未变化的整个目录。
4. **按同一目标比较整条链。** 比较现有路线与相关替代或组合路线的净交付、原料缺口、剩余产物、设备与功率、输送和投产成本。循环物料同时计算毛流量与净量，并安排启动料及回流；输出回流物料不等于存在净增产。副产物只有实际可达且有需求时才能抵扣供应，不能假定任意数量都能靠燃烧或存储消化。
5. **记录选择并验证。** 简记采用方案及关键淘汰原因，按 [统计诊断流程](production.md#基于统计优化产线)核对投产后的目标端收益。

例如“红糖缺氢、精炼油积压”时，应同时查氢的产出配方与精炼油的消耗配方，从数据发现 X 射线裂解，而不是只扩等离子精炼或加储油罐。若当前配方为每轮投入 1 精炼油和 2 氢、产出 3 氢和 1 石墨，则净增 1 氢和 1 石墨；这可能同时缓解两项问题，但仍要保留化工所需精炼油，确保启动氢、循环输送、石墨出口及下游红糖产能。油本身短缺或氢、石墨无去向时，不应照搬裂解方案。数量与可用性始终以当前游戏数据为准。

这套流程也用于普通与高效配方、奇珍矿物替代、直接采集与加工等选择；示例不是配方白名单。配方发现和选择属于外部 Agent，Mod 只提供原始目录与原生执行能力。

## 计算产线需求

统一速率单位、供应边界与目标口径，汇总科研、燃料、建造物资和其他产线的共同消耗。各生产组建筑数向上取整，区分目标供料与取整后全机满载需求。

公式、增产剂选择、多产物与循环配平，以及可直接运行的 JS 工具见 [产线需求计算](production-calculation.md)。采矿、分馏和其他特殊建筑按各自机制计算。

## 研究站的两种用途

矩阵研究站可生产矩阵，也可消耗矩阵研究科技。分别评估生产能力、送入研究站的吞吐和研究能力，结合材料库存趋势与科技进度定位限制。

某种矩阵积压而另一种不足时，优先补齐短缺项；同时检查研究站是否能持续获得该科技要求的完整材料组合。

有科研任务时，取入背包的矩阵可能被原生机甲研究收入点数缓存，不能假定导航后仍可转存给研究站。取料成功后若背包数量消失，先查询 `player.mecha.lab.itemPoints.items { key value }`，结合背包、物流格和实际研究进度确认去向；这里的 `value` 是科研点数，不是矩阵件数，也不是可直接转存的背包余量。缓存缺少某种必需矩阵时，优先补齐该项，避免反复取出已有缓存对应的矩阵。跨仓调拨前应计入机甲研究的自动消耗。

矩阵短窗产量低时，先核对科研站的 `matrixServed`、矩阵生产站的 `served/produced` 和供需箱库存。产出缓存已满且科研端有余料，可能只是停产等待消耗，不能据低产量认定该矩阵缺料。多条矩阵链共用中间品时，按当前科技的材料比例和已有库存分配供给，优先把现有产线余量接入共享物流，再评估扩产。临时限制备货或暂停补料时，记录恢复对象、原设置与触发条件，在库存接近不足或科研项目切换时恢复并重新配平。

研究完成以实际解锁或指定升级等级为准。相关接口、正常研究与元数据买断的资源语义见 [游戏控制接口](../interface/game-control.md)，科技字段见 [查询](../interface/game-state.md)。

科研物资预算使用原生点数单位：`techs.items.points` 是每个研究 hash 消耗的物料点数，不是物品数量；普通研究的剩余物品需求约为 `(hashNeeded - hashUploaded) × points / 3600`，准备整件物品时向上取整。研究站的 `matrixServed` 也是点数缓存，按 3600 点对应一件矩阵核对，不能直接当作件数。升级阶段使用当前原生 `hashNeeded`，并以实际材料消耗和解锁结果复核；不要把跨存档元数据买断当作供料。

## 科技前置的供应经验

根据当前缺口选用以下经验，相关能力已经具备时沿用现有供应：

| 当前需要 | 供应与建设取舍 |
| --- | --- |
| 持续生产电磁矩阵 | 配套磁线圈、电路板及基础冶炼；矩阵生产和科研消耗分别安排研究站，规模按近期科研需求计算 |
| 解锁能量矩阵相关科技 | 精炼获取氢时，同时安排精炼油去向。储油可支撑后续化工；裂解能增加氢供应，但会改变精炼油与石墨的平衡，结合后续需求选择 |
| 准备结构矩阵 | 核对钛供应、有机晶体及其化工前置。跨行星运输尚未自动化时，按一次可带回数量估算供应能维持多久，再决定科研与扩产规模 |
| 建立行星或星际物流 | 提前准备处理器、粒子容器及相关中间品；把物流建筑的材料与制造时间计入建设预算，已有硫酸等供应按实际余量共用 |
| 开发外星系资源 | 对比远端直接采集与本地加工链的成本；航行、前哨、运输和持续补给准备齐后，再用远端供应替换原有产线 |

进入新的资源区前，结合可用探索能力查看矿物分布。前哨物资按开采、加工、供电、仓储和返回补给预算，战斗模式再计入当地威胁。科技推进等待期间，可生产后续必需且已有稳定需求的建设物资。

首批钛硅的人工运输、星际物流启动预算、铜铁替代供应及奇珍矿物取舍见 [外星资源与扩张](interplanetary.md)。

## 目标与完成依据

| 目标 | 规划重点 | 完成依据 |
| --- | --- | --- |
| 指定科技或升级 | 前置科技、研究材料及研究能力 | 实际解锁或达到指定等级 |
| 指定白糖产速 | 相关科技、其他矩阵、光子与反物质供应、电力和物流 | 约定范围与游戏时间窗口内的实际生产速度 |
| 指定科研速度 | 研究材料、研究站及可研究项目 | 实际研究消耗或研究进度，按用户口径确定 |
| 指定戴森球功率 | 恒星条件、距离、资源、工业基础和施工供给 | 明确球体、戴森云、接收端或电网口径后验收 |
| 按蓝图建球 | 设计适配、科技、材料和发射吞吐 | 设计吻合，结构与壳面实际施工完成 |

布局、输送、仓储和瓶颈诊断见 [产线操作](production.md)。
