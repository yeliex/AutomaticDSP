# 大规模产线布局参考

规划成排扩建、多塔工业区或分馏循环时选读。按现场选择布局，不固定某个产物的排数、塔数或机器数量。配比见 [产线需求计算](production-calculation.md)，连接与运行见 [产线建设与运行](production.md)。

## 选址与加工分工

先按 [跨星球产线规划](interplanetary.md#跨星球产线规划)确定进口与本地加工边界，再为保留的工序安排空间。用物流站或大型采矿机汇集原料，可使加工区利用规整地块，不必紧贴每个矿簇。

选择能容纳完整模块及下一批扩建的连续地块，检查海岸、矿簇、采矿通路、取液点、供电和物流塔间距。

## 球面空间与工业区预留

长排建筑优先选择低纬度、网格变化较少的区域，沿东西方向展开，南北方向留给并排扩建。跨纬度网格分段时重新核对落点、朝向和接口，必要时拆成较短模块；高纬或极地可安排适合当地空间的物流与供电设施。

先安排物流塔、设备排、进出料通道、喷涂位置和扩建方向，再填入建筑。保留原生塔距、带口展开、转弯和坡道空间；供电设施及辅助带可利用边缘地块，避开生产排延长方向。

产线尽量沿游戏网格排列，同类建筑保持一致朝向和行列对齐。相邻产线的物流塔沿同一网格方向成列，喷涂区另成一列，并对齐相应供料接口，预留贯通的辅助带通道；这样一座补给塔可分别引出翘曲器带和增产剂带，沿公共通道直线延伸，以短支线或串联方式供应多条产线，减少逐线绕行和重复占用需求货槽。扩建时尽量延续这些对齐关系，按总消耗、末端供给和球面网格变化决定何处分区。

近邻模块共享主物料时，把对应进出料侧相对布置，减少跨线。

## 时间规划与分批投产

区分最终预留规模与本次实际建设规模。按当前瓶颈选择首批模块，预留下一批场地和接口；不要为了远期规模提前囤满所有物流塔或一次建完大量暂时无料可用的设备。

把物流站、运输工具、生产建筑、带线与供电的备货和运输提前安排，按能先投入使用的完整模块分批施工。首批模块有原料、有电、有输出去向并持续运转后，再沿预留方向扩建；等待备货或无人机落成时，可以推进独立的场地调查、运输与下一模块规划。保留首批启动所需的燃料、增产剂和翘曲器，避免新网络依赖尚未投产的自身产物才能启动。

迁移先让新模块稳定供货，再切换旧线；按 [统计诊断流程](production.md#基于统计优化产线)验收。比较方案时计入达到目标产量的时间及拆迁、重复建设成本。

## 一物一塔与成排布线

“一物一塔”可作为基础冶炼或中间品的模块模板：一座星际物流运输站围绕一种主要加工产物，接收原料，向成排设备供料，再收回加工产物并对外供应。这里的“一物”指主要产物，并非塔里只配置一种货物，也不要求每个物品都单独建塔。

| 货物用途 | 可选配置与连接 |
| --- | --- |
| 原矿或其他输入 | 按来源设置本地需求、星际需求，允许同时接收本星球与外星供应；出塔带送至加工排 |
| 加工产物 | 设备出料汇入回塔带，再按去向设置本地供应、星际供应；相邻工序也可直接接带 |
| 增产剂 | 需求所选等级，出塔后用辅助带送至喷涂机；也可由邻塔共用供应 |
| 空间翘曲器 | 有跨星系运输需要时补给，可由本塔需求，也可从邻塔经传送带输入专用缓冲 |

原料同时设置本地和星际需求并不等于“本地优先、缺口才进口”。若计划依赖特定来源或优先顺序，应结合实际可用物流设置、分塔或带线安排，并核对到货来源与流量。具体供需配置见 [跨星球运输](interplanetary.md#从人工运输转为持续供应)。

大型采矿机可储存矿物并提供本地供应，由需求站的物流运输机直接取矿；星际外运仍需接入星际物流运输站。核对供货状态、采矿供电和需求站运力。

每排设备沿直线共用进料带和出料带，依据现有量化结果及最紧张的输入或输出通路确定排长。带已饱和时增加独立供料的并行排，不继续在尾端堆机器；多条带从同一个饱和入口分出并不会增加总供料。高流量原料可从塔的不同端口分带供给不同排，产物汇流回塔前也检查合流后的容量。

短距分拣连接优先，把最繁忙的原料带靠近取料端，给其他原料和出料保留独立路径。交叉尽量集中在塔旁或设备排端部，用合法的分层带跨越，进入分拣区域前恢复适合取放的高度；不在每台设备旁反复升降绕线。延长或复制一排时一起延伸输入、输出、喷涂补给和供电，不能只复制机器。

按输入种类与流量、产物出口、设备端口和地块决定排布。高流量需要独立通路，多种低流量原料则更容易受带口和分拣空间限制。塔设在排端、喷涂集中在塔与设备之间，便于横向供增产剂和纵向扩建；也可按物料来源与去向调整塔位。逐条核对带上物料和流向，扩建时同时检查货槽与带口余量。

复用蓝图前检查建筑等级、运输站出货堆叠、分拣器升级及增产剂外接要求，按当前能力调整排长和供料。

## 喷涂位置与辅助物料共用

对同一批物料在两道工序之间的转运，可在入供应塔前喷涂，或在需求塔出料、进入下一工序前喷涂，二选一作为主要喷涂位置：

- 入塔前喷涂：把本模块加工产物喷好再回塔供出，便于下游共用；需确认其他供应来源是否同样喷涂，不能假定塔内混入的所有货物都具有目标等级。
- 出塔后喷涂：对输入加工排的物料统一喷涂，适合来源多样或各消费端喷涂要求不同的网络；每条实际使用的出料带都需覆盖，避免旁路漏喷。

上述二选一针对同一物流环节，不代表整条多工序产线只喷一次。加工后的新产物供下一工序使用时，按那一工序需求重新安排；效果与耗材仍沿用 [增产剂口径](production-calculation.md#增产剂口径)。增产剂可从一个邻塔的货槽输出，经公共辅助带分给附近喷涂机，核对总消耗及末端供给；只有通过物流运输接收增产剂的塔才需要为其配置需求货槽，直接供喷涂机的带不必经过每座塔。

空间翘曲器也可由一座塔统一需求，再用传送带分送附近星际塔。已解锁运输船曲速的星际塔可经传送带补充专用翘曲器缓冲，无需各自占用普通货槽需求；也可从专用缓冲继续出带串联供给下一座塔。专用缓冲不是额外的通用物流需求槽。布局时预留进出带口，检查近端补给后远端是否持续有货；范围过大或补给不稳时分区供应，不强求一条带覆盖整颗星球。出带筛选见 [传送带接口契约](../interface/game-control.md#物流设置)。

## 多原料产物的邻塔协作

高级产物的原料、成品、副产物及辅助物料可能超过单塔货槽数。先列出整个模块所需货物及出入方向，对照当前站的实际货槽、带口和运力，再分配邻塔职责；不能只解决货槽数量，却把所有高流量物料挤到同一条带或同一座塔的运力上。

例如一个需要多种输入的加工区，可以让 A 塔接收部分原料并收回成品，B 塔接收其余原料和增产剂；两塔分别向中间的设备排直接拉带，翘曲器由片区补给塔共用。A 塔没有必要再为已经从 B 塔直接供给设备的原料占一个货槽。相邻加工模块的产物若正是下一模块原料，也可以短带直供，在确有跨区调度或缓冲需要时再入塔。

一个产物可对应一组塔，一座塔也可服务相邻工序；按共享物料与扩建需求划分模块。

## 重氢分馏的循环模块

“重氢转转乐”适合把高流量循环限制在局部，物流塔只承担外部补氢、重氢外送及辅助物料供应。先区分补氢干线、氢循环带、重氢汇流带和增产剂带，再安排塔与模块的位置；未转化氢直接回到对应循环，不必每圈都回物流塔。分馏概率、喷涂与运行诊断沿用 [分馏运行说明](production.md#连接与吞吐)，这里只比较布局。

| 循环结构 | 空间与布线取舍 | 扩建时重点检查 |
| --- | --- | --- |
| 多塔长串联后回流 | 多台共用一条循环，补料与回流连接集中 | 沿途转化会减少后段氢通过量；比较缩短串联、分段补料或拆成并行循环，不能无限延长 |
| 数台一组的并行短循环 | 每组单独回流和补料，共用外部补氢与重氢汇流干线 | 各组入口流量、回流畅通与干线总容量；适合分批启用、按组扩建 |
| 单机小循环重复排列 | 每台就近回流，从公共氢带补料，重氢独立引出再汇流 | 分拣器、集装设施和带线连接更多；比较占地、建设成本及实际循环吞吐，不以密铺程度代替效率 |

**补氢与循环。** 把补料入口放在能持续接收的汇入位置，让回流优先，外部氢补足净消耗。长串联后段缺氢时，新增补料点也必须有独立供应余量及合法汇流，不能在已满的回流出口继续硬塞。需要堆叠时，核对塔出货、集装设施和补料方式能否维持实际堆叠；局部集装只改变带上运输状态，不增加外部氢来源。原生端口连接及供电仍是前提。

**重氢汇流。** 氢循环口与重氢产物口分别布线，避免产物进入氢回路。并排模块可将重氢集中引向同侧，沿模块边缘送回物流塔；每增加一组都检查汇流后流量、回塔带口及运输站库存。出口已满时先恢复外送或下游消耗，继续建分馏塔不能解除堵塞。

**启动与建设顺序。** 循环库存、持续净补氢是不同需求。先打通重氢出口与外送，再分批给循环充氢，观察首尾通过量、回流及供电稳定后启用下一组；不要把填充大型循环的短时高耗氢当成稳态消耗，也不要在尚未充满时用瞬时产量判定布局失败。复用模板前检查增产剂槽是否只是仓储、喷涂带是否接好，以及当地电力能否承受启用喷涂后的工况。

**球面拼接。** 按纬度选择适配当地网格的模块，沿片区边界保留补氢、重氢外送和供电通道；确认一组通过原生建造与连接校验后再扩展。
