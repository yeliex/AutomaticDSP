# 外星资源、运输与规模化扩张

## 先探测，再决定去哪里

开局母星通常没有可开采的钛、硅矿脉，但应以当前存档可见资源为准，不能仅按星球类型推断。先读当前科技、`history.universeObserveLevel`、机甲推进器等级及星系/行星状态，再比较已探测候选的钛、硅、铜、铁、煤、海洋、供电条件、距离和威胁。没有探测权限、扫描未完成、没有加载工厂和真实矿量为零是不同状态；未知不能按零处理，也不能通过种子或原始对象绕过探索科技。

矿物总量用于选星；落地后再读矿脉位置与剩余量决定矿机布局。天体 ID、宇宙坐标与行星局部坐标分开使用，实体 ID 只在所属工厂有效。选星、落点、规模与物料调度由 Agent 决定；指定目的地的飞行控制可交给 `navigateTo`。

## 第一批钛与硅

本地采集部分石头可能获得少量钛矿，只适合眼前缺口，不保证每块石头都有掉落。核对采集对象与实际背包增量。低效补硅路线是石料→硅石→高纯硅块，不是玻璃；按当前配方查询投入、产量、耗时和增产效果，再比较本地加工与外星采矿的成本。

具备宇宙航行后，优先评估附近行星的天然硅、钛矿，而非持续扩大低效的本地补硅设施。第一次出航携带采矿、供电、熔炼、连接和单品缓冲所需建筑，并准备适用的高等级燃料及返程储备；留出带回货物的背包空间。前哨发电方案按当地条件与已解锁能力选择。

优先在产地将钛矿加工成钛块，再搬回母星；硅也比较加工为高纯硅后的携带效率。按当前配方、堆叠上限、目的地用途和前哨电力计算每格有效货量，不假定所有加工都更省格子。首批带回数量应覆盖目标科技、黄糖前置、物流塔和运输船等启动成本，并留建设余量；避免把全部钛投入科研后无料建立物流。

## 从人工运输转为持续供应

按实际科技前置推进星际物流，区分行星物流站与星际物流运输站。先准备物流塔、运输工具、必要中间品、派船站充电和两端生产设备供电，再建立供需设置与单品缓冲。同星系运输不必等待曲速能力；跨星系则评估航行时间、翘曲器供应与运输相关升级。

使用 `setStationStorage` 配置货槽及本地/远程供需，`setStationVehicles` 从真实背包放入或取回闲置运输工具。输出带创建时必须一并指定 `filterItemId`，输入带按原生货槽接收。核对充电功率、起运量和实际运输记录，验证目的地库存持续恢复后再降低人工搬运频率。供应方或需求方任意一边有运输船即可承担运输，无需两端都配置；再按吞吐、供电和往返时间决定数量。快速填充运输站会补运输工具，不能当作指定货槽填料。

运输机、运输船从所属派出站的储能支付运输能量，不需要在另一端补充燃料。早期外星采矿可由母星需求站配置运输船并充电，产地供应站不放运输工具、不接电，作为被动收发货站；产地矿机、熔炉和分拣器仍需正常供电。若产地站也承担主动派机或派船任务，则必须为它供电，不能把“产地站无需供电”当成通用规则。

接电站先用 `setStationChargePower` 设置原生允许的最低充电上限，再结合运输频率、往返耗能、储能恢复和电网余量调整；最低上限不保证满足任意吞吐。充电上限不是固定耗电，也不是供电预算必须达到的发电功率；按实际充电和储能变化判断，避免为了匹配上限盲目扩建电源。被动站不接电与接电后设最低上限是两种方案，最低设置仍可能造成充电负荷。

本地铜、铁也会因科研、建筑和燃料链扩张而短缺。持续观察矿量、采集吞吐和库存变化，提前建设替代矿区或外星供应，不能只关注钛、硅。短缺先区分枯竭、矿机覆盖、供电和运输瓶颈。

## 后期选址与奇珍矿物

大规模产线按目标吞吐选择有足够建设空间、可持续能源、合适海洋和资源供应的行星；结合运输距离、物流吞吐、战斗威胁和维护成本分配采矿前哨、冶炼与成品生产。不要把母星的零散开局布局无限复制。

探测到奇珍矿物后，从当前已解锁配方比较其替代链，核对设备、总原料、耗电、运输与矿量续航；例如天然有机晶体或硫酸海洋可减少相关化工环节，但必须以实际资源和配方为准。稀有资源不等于无限供应，未建立稳定运输前保留必要的旧供应能力。

## 航行准备与抵达

出发前查询 `player.flight`，核对推进器能力、核心能量、燃烧室燃料和翘曲器，准备着陆及返程储备。曲速启动需比较 `coreEnergy` 与 `warpStartEnergy`；背包有燃料不代表核心能量足够。能量不足时先补给或充能，也可接受普通航行。科研与手搓可并行，但要计入共同的能量和库存消耗。

优先用 `navigateTo` 指定星球及落点；长距离可传 `useWarp:true`。曲速条件不满足时会继续普通航行，通过结果 `warpUsed` / `warpStatus` 判断实际使用情况。目的地坐标、容差和低层飞行输入参数见 [飞行与导航](../interface/game-control.md#飞行与导航)。

落点应避开已有建筑。气态星先查采集器位置，选择附近可到达的悬停点；不要将采集器中心当作机甲落点。安装轨道采集器时选择符合原生间距要求的赤道位置，建成后检查实际气体库存增长。

固态星抵达以接地为准，气态星以目标附近低速悬停为准。太空点仅表示进入或穿过容差范围，不保证停车或持续驻留；取消、超时后仍可能保持速度或曲速，先读取真实状态，再决定退出曲速、制动或重新导航。不要重复相同失败指令消耗能源。
