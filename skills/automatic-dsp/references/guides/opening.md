# 开局到第一条基础产线

适用于新开局或基础工业尚未建立的存档。结合已有科技、库存和生产设施选择当前有收益的动作，完成的环节直接复用。

## 把初始物资转为可用能力

新建对局的参数选择、落地观察、飞行仓回收与能源准备见 [游戏初始化](initialization.md)。进入产线规划前，先以准备完成后的背包、科技和设施状态为依据。

从近期目标所需科技反查材料，先用背包和可取用仓储满足需求，再采集缺口。例如现有磁铁和铜块足够制造研究电磁学所需的磁线圈时，可直接手搓推进研究。科技解锁后重新清点奖励建筑和材料，将它们计入第一条产线的建设预算。

资源与手搓取舍见 [机甲操作](mecha.md)。

## 尽快形成可运行的短产线

以铁块线为例，形成“矿脉 → 采矿机 → 输送 → 熔炉 → 成品出口”的闭环，并配齐供电、配方及所需分拣器。电磁学、自动化冶金、基础物流系统是这类基础产线可核对的科技；根据当前解锁与建造需求决定先后及材料预算。

手动采集按当前小量缺口和行动时间选目标；自动化矿区还需考虑覆盖点、储量、可建空间、输出方向及带长。矿机覆盖更多矿脉点通常能提高产速，比较时同时检查输送和下游消耗能力。

附近风力涡轮机若能直接覆盖用电建筑，可减少初期电塔投入；覆盖或连接不足时再补电塔。先使短线产出，再沿预留方向扩展。选址和连接细节见 [建设与运输](production.md#连接与吞吐)。

## 从首条产线转向持续科研

首条产线运行后，检查下一项关键科技和反复手搓的材料需求。优先把持续消耗的基础材料及常用建设物资接入自动化，让新增设备能减少采集、等待和手搓时间；短期少量缺口继续利用已有库存或手工制造。

电磁学提供初期发电、供电和采矿能力，后续加工与物流科技让原料连续进入设备。按当前缺失的环节补齐能力，再结合目标所需科技决定矩阵供应。研究站的矩阵生产与研究消耗分别配套，观察材料送达和研究进度后调整产量。

规模扩大时一起核对供电、燃料、运输与成品出口。完整供需计算见 [产线需求计算](production-calculation.md)，故障处理见 [产线操作](production.md)。

## 用实际产出检验建线结果

确认建筑落成、配方正确、供电正常及物料可达，并检查成品出口。首次产出说明闭环已打通；持续生产还需观察库存、堵塞和上下游速率。

放置失败后根据现场调整：交互距离影响机甲位置，连接距离影响建筑与带段的选择，碰撞则需检查周围对象和地形。试建位置不合适时，可评估拆除回收后重放，保留邻近设施的供电和物流连接。接口错误含义见 [游戏控制接口](../interface/game-control.md)。
